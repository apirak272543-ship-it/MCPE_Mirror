# MCPE Studio ฉบับภาษาไทย

หน้านี้คือ **เครื่องมือทำโลกและส่วนเสริมแบบเปิดแยกจากเกม** ใช้สร้างหรือปรับแต่งไฟล์ที่โปรเจกต์ของเราต้องใช้ร่วมกัน เปิดได้จาก `studio/index.html` หรือ URL `/MCPE_Mirror/studio/` บน GitHub Pages

## วิธีเริ่มใช้งานและบันทึกงาน

กด **เลือกโฟลเดอร์งาน** แล้วเลือกโฟลเดอร์ `projects/addons` ในโฟลเดอร์ MCPE_Mirror ของคุณ จากนั้นเลือกไฟล์ที่ต้องการแก้ไขทางแถบซ้าย พิมพ์หรือปรับค่าในช่องแก้ไข และกด **บันทึกการแก้ไข** ไฟล์จะถูกเขียนลงเครื่องของคุณโดยตรง ไม่มีการส่งข้อมูลขึ้นเซิร์ฟเวอร์

ถ้ากดเลือกโฟลเดอร์ไม่ได้ ให้ใช้ Chrome หรือ Edge รุ่นใหม่บน HTTPS และอนุญาตให้เว็บเข้าถึงโฟลเดอร์เมื่อระบบถาม สิทธิ์นี้จำเป็นเพราะหน้าเว็บต้องเขียนไฟล์ลงเครื่องของคุณ

## การทำงานร่วมกับเกม

Studio กับเกมเปิดคนละหน้าและทำงานแยกกัน แต่ใช้โฟลเดอร์งานเดียวกันคือ `projects/addons` เมื่อบันทึกเสร็จให้กด **ไปหน้าเล่นเกม** เพื่อกลับไปทดสอบ ผลงานจะถูกส่งต่อผ่านไฟล์ในโฟลเดอร์ ไม่ได้เชื่อมแบบแก้หน่วยความจำของเกมขณะกำลังเล่น

> ไฟล์บางชนิดที่สร้างจาก AddonCrate อาจเป็นรูปแบบของ Bedrock รุ่นใหม่ ขณะที่ MCPE target ของเราอาจยังอ่านไม่ออก หากแก้ไฟล์แล้วไม่เห็นผลในเกม ไม่ได้แปลว่า Studio บันทึกผิด แต่อาจต้องเพิ่มตัวแปลงไฟล์ในฝั่งเกมก่อน
